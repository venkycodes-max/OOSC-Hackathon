# Trailhead Light + Dark Theme Redesign

This frontend uses a centralized theme system driven by CSS variables and the `dark` class.

## Light mode
- White/light surfaces with navy primary text
- Slate secondary text for readable hierarchy
- Purple/blue gradient accents
- Theme-safe footer, CTA, cards, sidebar and code editor

## Dark mode
- Deep navy page background
- Dark surface cards with light primary text
- Purple/blue active states and accents
- Theme-safe footer, CTA, sidebar and code editor

The implementation avoids relying on hard-coded white text inside theme-adaptive panels.
