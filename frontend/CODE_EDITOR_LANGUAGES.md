# Code Editor Languages

Trailhead's Code Editor is available to:

- Class 8, 9, 10, 11 and 12 students
- UG Year 1-4 students whose branch is Computer Science

Supported languages:

- JavaScript
- Python
- C++
- Java

JavaScript runs in a browser sandbox. Python, C++ and Java are executed through the Piston online code execution service when the student presses **Run**. No code is stored by Trailhead's backend by this feature.

The code editor is a practice tool, not a production-grade compiler environment. External execution can be temporarily unavailable or rate-limited.
